# Coworking Booking

REST-сервис бронирования рабочих столов и переговорных комнат в коворкинге.

Пользователи бронируют рабочие места на нужный интервал времени, администратор управляет местами.
Главная задача сервиса — исключить пересечение броней, в том числе при одновременных запросах.

## Возможности

- Бронирование стола или переговорной на интервал времени
- Отмена брони и просмотр своих бронирований
- Поиск свободных мест на заданное время
- Управление рабочими местами (для администратора)
- Защита от двойного бронирования

## Роли

| Роль | Что может |
|------|-----------|
| Пользователь | Искать свободные места, бронировать, отменять свои брони |
| Администратор | Создавать, изменять и отключать рабочие места |

## Основные сущности

- **User** — пользователь сервиса
- **Workspace** — рабочее место: стол или переговорная комната
- **Booking** — бронь места на интервал времени
